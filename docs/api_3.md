# API: Создание нового объекта (`POST /objects`)

Ресурс для создания нового объекта.

---

## Описание запроса

| Параметр | Значение |
| --- | --- |
| **Метод** | `POST` |
| **URL** | `https://api.restful-api.dev/objects` |
| **Аутентификация** | Не требуется |
| **Тип контента (Content-Type)** | `application/json` |
| **Формат ответа** | JSON с новым объектом |

---

### Примеры запросов

#### cURL

```bash
curl -X POST https://api.restful-api.dev/objects \
  -H "Content-Type: application/json" \
  -d '{
    "name": "new name",
    "data": {
      "title": "new object",
      "body": "this is a text for object's body",
      "userId": 1
    }
  }'
```

#### JSON

```jsonc
{
  "name": "new name",              // обязательное
  "data": {                          // объект с деталями
    "title": "new object",           // обязательное
    "body": "this is a text for object's body",      // обязательное
    "userId": 1                      // обязательное, integer
  }
}
```

|Поле	|Тип	|Обязательность	|Примечания|
| --- | --- | --- | --- |
|name	|string|	да |  не пустой. Ярлык/имя объекта для поиска, фильтрации и отображения в списках. Должно быть коротким и понятным.   |
|data.title	|string|	да |  не пустой. Содержательный заголовок объекта. Может быть длиннее, используется как основной заголовок при просмотре карточки.  |
|data.body	|string|	да |  не пустой   |
|data.userId	|integer	|да| Должен быть валидным ID пользователя  |


## Коды ответов и поведение
|Код	|Статус	|Поведение API	|Что документировать для разработчика|
| --- | --- | --- | --- |
|200 |OK	|Успех	|Возвращает JSON с данными нового объекта |	
|400 |Bad request	|Ошибка в запросе	|Возвращает  "error": "Invalid request body" |	

## Формат успешного ответа (200 OK)
```json
{
    "id": "ff808181a09d98f701a0c97c851d6f4a",
    "name": "for deletion",
    "createdAt": 1790086776093,
    "data": {
        "title": "deletion",
        "body": "deletion",
        "userId": 5
    }
}
```

## Структура ключевых полей
|Поле	|Тип	|Описание	|Ограничения / примечания|
| --- | --- | --- | --- |
|id|	string	|Уникальный идентификатор созданного объекта	|Генерируется  системой|
|name	|string|	Ярлык/имя объекта для поиска, фильтрации и отображения в списках |Не пустой|
|createdAt	|integer (timestamp)	|Время создания объекта (в мс)|	UTC, Unix timestamp|
|data.title	|string|Заголовок объекта|Как передано в запросе|
|data.body	|string|Текст содержимого объекта|Как передано в запросе|
|data.userId	|integer|ID пользователя, связанного с объектом|Как передано в запросе|

## Ограничения и особенности (демо-API)

- Статус-код для успешного создания — `200 OK` вместо ожидаемого `201 Created`. Это специфика демо-сервиса.
- Лимиты на длину полей (`name`, `title`, `body`) не зафиксированы публично. Рекомендуется тестировать на граничных значениях.
- Данные не сохраняются надолго: объекты могут удаляться при сбросе сервиса.
- Нет rate limiting и детальных кодов ошибок: большинство проблем с валидацией приводит к `400 Bad Request`.

## Связанные эндпоинты

- `GET /objects` — получить список объектов или конкретный объект по ID.
- `PUT /objects/{id}` — обновить объект.
- `DELETE /objects/{id}` — удалить объект.
- `GET /users` — проверить существование `userId` перед созданием объекта.
